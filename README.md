# FabCon 2026 Release Tracker

A shareable, self-contained HTML guide to Microsoft Fabric, Power BI, OneLake, AI, platform, and SQL announcements from **FabCon & SQLCon 2026**.

| File | Description |

Includes 29 detailed announcement cards with search, filters, and links to official sources. |
| [fabcon-2026-releases.html](./fabcon-2026-releases.html) | Combined Atlanta + Barcelona release tracker with checklist-style review tracking (tick items off, saved in your browser). |

## How to open

These are static HTML files — no build step or server required.

1. Double-click the `.html` file to open it in your default browser, **or**
2. In VS Code, right-click the file → **Reveal in File Explorer**, then double-click it, **or**
3. Paste the file path into your browser address bar, e.g.:
   ```
   file:///C:/Users/ymuralidhar/Documents/Microosft%20Fabric%20-%20FabCon%202026/fabcon-2026-barcelona-releases.html
   ```

> These are currently **local files**. To share a live `https://` link with others, publish the HTML to a host such as GitHub Pages, SharePoint, or Azure Static Web Apps.

## Features (Barcelona release guide)

- Search by feature, product, or use case
- Filter by category and availability status (GA, Preview, Coming soon, Announced)
- Grid or list view toggle
- Light/dark mode (auto-detects system preference, or override with `?scoutTheme=light` / `?scoutTheme=dark`)
- Copy page link and print/save-as-PDF actions
- Direct links to official announcements, feature deep-dive blogs, and the Fabric roadmap for every item
